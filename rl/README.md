# P5 — Deep RL Baselines

PPO and SAC (Stable-Baselines3) trained in f1tenth_gym, evaluated on
simulator-seconds-to-parity against hand-tuned classical controllers.

## Interface contract
- Gymnasium 5-tuple API stays inside sims/gym_env.py — not imported here.
- Wrappers conform to common/interface.py (frozen).
- Outputs logged to results/ in P4's CSV schema.

## Headline metric
Simulator-seconds consumed to reach a threshold lap time, converted to
wall-clock cost at 20 Hz control (AutoDRIVE real-time equivalent).
5 seeds per algorithm; seed spread reported, not averaged away.

## Layout
- `rl/wrappers/`: Gymnasium environment wrappers for SB3
  - `racing_env.py`: Core SB3 gym wrapper around GymEnv with configurable reward shaping
  - `normalize_obs.py`: Running-mean observation normalisation
  - `frame_stack.py`: Temporal frame-stacking wrapper
  - `domain_randomization.py`: Dynamics & observation perturbation for sim-to-real transfer
- `rl/train_ppo.py`, `rl/train_sac.py`: Training entrypoints (with checkpointing and TensorBoard support)
- `rl/evaluate.py`: Policy evaluation against frozen metric
- `rl/run_multi_track.py`: Generalisation testing across circuits
- `rl/sweep.py`: Hyperparameter grid/random search runner
- `rl/plot_curves.py`: Learning curve plotting vs simulator-seconds
- `rl/plot_comparison.py`: PPO vs SAC evaluation bar chart comparisons
- `rl/configs/`: Hyperparameters (`ppo.yaml`, `sac.yaml`, `reward.yaml`, `sweep.yaml`)

## Real-time cost at AutoDRIVE 20 Hz

AutoDRIVE advances in real time at 20 Hz control, so **one AutoDRIVE step = 0.05 s wall clock**.
A budget of `S` simulator-seconds spent in f1tenth_gym would cost `S` real seconds in AutoDRIVE
at 100 Hz (matching `GymEnv`'s `DT = 0.01`), or `S` real seconds again at 20 Hz because the
control rate only changes the number of decisions per sim-second, not the sim-second itself.
The **useful comparison** is: *how many AutoDRIVE wall-clock minutes does the same learning
budget represent?* — i.e. `S` sim-seconds = `S` real seconds of AutoDRIVE time.

Budget allocation per `rl/configs/{ppo,sac}.yaml`:

| algo | seeds | steps/seed | simulator-seconds/seed | total sim-seconds | AutoDRIVE real-time eq. |
|------|-------|------------|------------------------|-------------------|-------------------------|
| PPO  | 5     | 100,000    | 1,000 s                | 5,000 s           | ~83.3 min               |
| SAC  | 5     | 100,000    | 1,000 s                | 5,000 s           | ~83.3 min               |

See `rl/figures/curves.png` (generated by `python -m rl.plot_curves`) for learning curves,
and `rl/figures/comparison.png` (generated by `python -m rl.plot_comparison`) for policy evaluation metrics.
