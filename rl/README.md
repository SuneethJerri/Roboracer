# P5 — Deep RL Baselines

PPO and SAC (Stable-Baselines3) trained in f1tenth_gym, evaluated on
simulator-seconds-to-parity against hand-tuned classical controllers.

## Interface contract
- Gymnasium 5-tuple API stays inside sims/gym_env.py — not imported here.
- Wrappers conform to common/interface.py (frozen).
- Outputs logged to results/ in P4's CSV schema.

## Headline metric
Simulator-seconds consumed to reach a threshold lap time, converted to
wall-clock cost at 20 Hz control (AutoDRIVE real-time equivalent).
5 seeds per algorithm; seed spread reported, not averaged away.

## Real-time cost at AutoDRIVE 20 Hz

AutoDRIVE advances in real time at 20 Hz control, so **one AutoDRIVE step = 0.05 s wall clock**.
A budget of `S` simulator-seconds spent in f1tenth_gym would cost `S` real seconds in AutoDRIVE
at 100 Hz (matching `GymEnv`'s `DT = 0.01`), or `S` real seconds again at 20 Hz because the
control rate only changes the number of decisions per sim-second, not the sim-second itself.
The **useful comparison** is: *how many AutoDRIVE wall-clock minutes does the same learning
budget represent?* — i.e. `S` sim-seconds = `S` real seconds of AutoDRIVE time.
